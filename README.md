😊 AI Face Emotion Detection System

A real-time facial emotion recognition web application using Deep Learning, CNN, OpenCV and Flask.

The system detects human emotions from webcam input and predicts the emotion with confidence score.

---

## 🚀 Features

- Real-time webcam emotion detection
- Face detection using OpenCV Haar Cascade
- CNN-based emotion classification
- Confidence score prediction
- Flask web application
- User-friendly interface

---

## 🧠 Emotions Detected

The model can recognize:

- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise
